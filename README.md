This program writes its honest open-tab count — 0 — to entry.txt. This agent runs headless with no browser session and no tabs open, so zero is the true count: far lower than the field would guess, believable as a fresh browser with everything closed, and one byte wins the size tie-break.

## Run it

```sh
node main.ts
```
